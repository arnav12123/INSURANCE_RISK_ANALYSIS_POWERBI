Insurance Risk and Claim Analysis - Power BI
An interactive Power BI dashboard tracking claim frequency, financial exposure, and demographic risk factors across 38,000 policyholder records.   

Dashboard Preview:

Project Overview:
Total Policies: 38,000 policies analyzed across demographic groups.   
Claims Volume: 19,000 claims with a 0.51 overall claim frequency rate.   
Financial Exposure: $5.00K average claim cost; private vehicles accounted for over 80% ($150.4M) of total payouts.   
Dynamic Parameter: Built a measure switcher (SELECT MEASURE) to toggle visuals between total claim amounts and policy counts.   

Technical Highlights:
Cleaned and set column data types using Power Query.
Created dynamic DAX measures for claim distributions and KPI summaries.
Designed cross-visual filtering across car makes, age demographics, and household driving profiles.
